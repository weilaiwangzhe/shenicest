# 换电脑使用清单

本交付包只保留 Guarded 一个路演运行版本，避免对方误选入口。

## 运行前

1. 安装 Python 3.10 或更高版本，安装时勾选 Add python.exe to PATH。
2. 安装腕带驱动：`03_驱动和说明\cp2102驱动.rar`。
3. 插入唯理腕带和 Nano，在设备管理器里确认 COM 口。
4. 不确定端口时，双击根目录的 `查看串口.bat`；AI 也可以读取它或运行 `detect_ports.py --json`。

## 烧录 Nano

默认烧录到 `COM5`：

```bat
02_烧录\烧录_Nano_闭环固件.bat
```

直接双击时，脚本会先自动识别 Nano 的 COM 口；识别不唯一才会询问。这里只烧 Nano，腕带不用烧录。

如果 Nano 是其他端口，例如 `COM9`：

```bat
02_烧录\烧录_Nano_闭环固件.bat COM9
```

## 安装运行依赖

```bat
01_运行\setup_runtime.bat
```

## 启动力反馈

默认自动识别腕带和 Nano 串口：

```bat
01_运行\run_roadshow_guarded_portable.bat
```

文件名和参数已经统一为 guarded 强震版。

直接双击时，脚本会先自动识别腕带/Nano 分别是哪一个 COM 口；识别不唯一才会询问。

如果端口不同，或自动识别失败：

```bat
01_运行\run_roadshow_guarded_portable.bat --emg-port COM7 --nano-port COM9
```

## 排查

检查腕带 EMG：

```bat
01_运行\run_emg_diag_portable.bat
```

检查 Nano：

```bat
01_运行\verify_nano_portable.bat --port COM5 --seconds 5
```
