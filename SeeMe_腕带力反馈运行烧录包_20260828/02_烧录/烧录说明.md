# Nano 烧录说明

推荐烧录文件：

```txt
firmware_closed_loop.hex
```

烧录脚本：

```txt
烧录_Nano_闭环固件.bat
```

默认烧录到 `COM5`：

```bat
烧录_Nano_闭环固件.bat
```

直接双击时，脚本会先自动识别 Nano 的 COM 口；识别不唯一才会询问。

如果设备管理器里看到 Nano 是其他端口，例如 `COM9`：

```bat
烧录_Nano_闭环固件.bat COM9
```

脚本会先尝试 Nano 常见的新 bootloader 波特率 `115200`，失败后再尝试旧 Nano 常见的 `57600`。

这里只烧 Arduino Nano。唯理腕带不用烧录，它只通过串口把 EMG/IMU 数据发给电脑。

烧录成功后，去 `01_运行` 运行：

```bat
verify_nano_portable.bat --port COM5 --seconds 5
```

如果能看到稳定输出，再运行：

```bat
run_roadshow_guarded_portable.bat
```

本交付包只保留当前闭环固件，避免误烧旧固件。
