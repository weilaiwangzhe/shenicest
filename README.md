# WebGL AR 化妆动作引导 + 腕带震动提醒闭环

一个纯前端 + 本地腕带桥接的演示系统：在浏览器摄像头画面上实时追踪人脸与手部，
用 Three.js/WebGL 将真实 3D 化妆工具贴合到面部进行动作示范；同时持续判定指尖是否
离开当前化妆区域，一旦离开就通过 WebSocket 把震动指令发给腕带桥接程序，驱动腕带震动提醒。

人脸与手部图像只在浏览器本地处理，不上传任何服务器。

## 功能总览

### 3D 化妆动作引导（前端渲染）

- 无摄像头时显示由参考照生成的 478 点三维面部曲面；摄像头模式生成带实时视频纹理的 3D 人脸曲面
- 接入官方兼容清单的 **61 种化妆动作**，按遮瑕、眉毛、眼影、眼线、粉底、腮红、面部/鼻部修容、高光、定妆和唇妆分类选择
- 二维笔触通过 canonical face 的三角面与重心坐标绑定到三维脸面，左右转头、抬头、倾斜时工具沿人脸三维法线同步旋转
- 11 类动作按语义使用 5 个真实闭合 GLB 工具（眉笔、眼影刷、腮红刷、唇线笔、海绵），启用正常深度遮挡
- 工具采用接触面质心对齐、动态倾角和真实三角碰撞；海绵/刷毛允许受控柔性按压，金属与杆身禁止进入脸面
- 直接加载官方 97 个 478 点化妆区域定义（`public/regions/all.json`），按每个动作 JSON 的 `regionSlots` 显示对应区域填充与边界
- 每轮动作自动镜像，交替示范左右脸
- 摄像头和实时人脸纹理保持原始颜色，不做磨皮、调色或妆后滤镜

### 手部追踪与腕带震动闭环

- **指尖识别**：MediaPipe HandLandmarker 追踪手部 21 个关键点，使用食指指尖、中指指尖、掌根 3 个关键点参与判定（任一在区域内即算「手在区域内」）
- **边界判定**：
  - 闭合区域（粉底、腮红等）：多边形包含判定 + 容忍带——指尖即使出了边界，只要距边界不超过容忍距离（默认约 3% 脸宽）仍算在区域内；画面上橙色实线是区域边界，**虚线圈是实际判定的最外边界**
  - 开放曲线区域（眼线等）：指尖到曲线距离小于阈值（默认 9% 脸宽）即算在区域内
  - 阈值均按实时脸宽比例计算，人脸离摄像头远近变化时自动缩放
- **震动状态机**（`idle → out → vibrating`）：
  - 指尖离开区域超过 250ms（防抖）→ 发送震动指令
  - 震动期间每 400ms 重发一次指令（喂 Nano 固件的 3 秒看门狗），保持持续震动
  - 指尖回到区域 → 立即发送停止指令
  - 手最近 4 秒内没出现在画面中 → 不判定，防止未伸手就误震
  - 桥接断开时不再续发指令，腕带 3 秒后自动停震（固件看门狗兜底）
- **腕带桥接**：浏览器 → WebSocket `ws://127.0.0.1:8787` → `nano_bridge.py` → Nano 串口（250000 baud）
- **状态徽章**：页面右上角实时显示 `腕带桥未连接 / 已连接 · 等待手进入区域 / 手在区域内 / 已离开·震动中`
- **离线运行**：MediaPipe WASM 与人脸/手部模型全部本地化（`public/vendor/wasm`、`public/models/*.task`），无需外网

## 环境要求

- Node.js 22.17.1（见 `.node-version`），包管理器 pnpm 11.24.0（通过 corepack）
- 摄像头必须在 `localhost` 或 HTTPS 环境下使用
- 使用实物腕带时需要 Python 3.13 和 CP2102 驱动（见腕带包 `03_驱动和说明`）

## 快速开始（前端）

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm dev --port 5175 --strictPort
```

打开 `http://localhost:5175/`，点击「开启摄像头」并授权。

## 启动腕带桥接服务

桥接程序位于 `SeeMe_腕带力反馈运行烧录包_20260828\01_运行\`。

### 无实物腕带（dummy 模式，验证链路用）

```powershell
& "SeeMe_腕带力反馈运行烧录包_20260828\01_运行\run_nano_bridge.bat" --dummy
```

不连接串口，所有指令直接打印在终端。当页面判定指尖离开区域时，终端会实时打印
`命令 → '3'`（震动）、`命令 → '0'`（停止），以此验证浏览器 → 桥的完整链路。

### 有实物腕带

插上腕带后直接运行（自动识别 COM 口）：

```powershell
& "SeeMe_腕带力反馈运行烧录包_20260828\01_运行\run_nano_bridge.bat"
```

如自动识别失败，可手动指定：`run_nano_bridge.bat --nano-port COM5`。

### 通讯协议

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| 桥 → 页面 | `{"type":"ready","nano_port":"COM5"}` | 握手，页面徽章变为已连接 |
| 页面 → 桥 | `'3'` / `'0'` | 震动 / 停止（也支持 `'1'`~`'3'` 强度档位） |
| 桥 → 页面 | `{"type":"ack","cmd":"3"}` | 指令已下发确认 |

## 端到端测试步骤

1. 启动前端（见上）并启动桥接服务（建议先 `--dummy`）
2. 页面右上角徽章变为「腕带桥已连接 · 等待手进入区域」
3. 开启摄像头，从下拉框选择一个动作（如「粉底整个脸拍开」），画面出现橙色化妆区域与虚线容忍圈
4. 把手伸入画面，指尖落在区域内 → 徽章显示「手在区域内」
5. 指尖移出虚线圈并保持约 0.25 秒 → 徽章变为「已离开 · 震动中」，桥终端打印 `命令 → '3'`
6. 指尖移回区域 → 桥终端打印 `命令 → '0'`，震动停止

## 灵敏度调参

所有参数在 `src/main.js` 顶部（「手部离开化妆区域 → 腕带震动」常量区），保存即热更新：

| 常量 | 默认值 | 作用 |
| --- | --- | --- |
| `HAPTIC_REGION_PAD` | `0.03` | 闭合区域容忍带宽度（脸宽比例）。**调大更宽松、调小更严格**，虚线圈同步变化 |
| `HAPTIC_OPEN_TOL` | `0.09` | 开放曲线（眼线等）判定带宽（脸宽比例） |
| `HAPTIC_LEAVE_MS` | `250` | 离开区域多久后触发震动（防抖延迟，毫秒） |
| `HAPTIC_HOLD_MS` | `400` | 震动期间重发指令间隔（毫秒，须小于固件 3s 看门狗） |
| `HAPTIC_ARM_MS` | `4000` | 手多久未出现则暂停判定（毫秒） |
| `HAPTIC_OPEN_MIN_PX` | `0.02` | 各阈值的归一化坐标下限，防人脸太远时阈值过小 |
| `HAND_KEYPOINTS` | `[8, 12, 0]` | 参与判定的手部关键点（食指指尖/中指指尖/掌根） |
